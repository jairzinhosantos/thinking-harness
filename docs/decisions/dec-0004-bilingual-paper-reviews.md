# Reviews bilingües: política sustituida

Decisión adoptada el 2026-10-01, [issue 17](https://github.com/jairzinhosantos/thinking-harness/issues/17).
Estableció una review principal en inglés y traducción completa `.es.md` para cada paper,
con una identidad, revisión compartida y actualización conjunta.

Las traducciones debían conservar fuentes, ecuaciones, código, cantidades, limitaciones y
estados de lectura, discusión y reproducción. La revisión editorial verificaba equivalencia;
CI no demostraba fidelidad semántica.

**Sustituida por [dec-0008](dec-0008-spanish-primary-documentation.md):** una nota principal
en español y traducciones solo cuando exista una audiencia concreta. Se conserva esta decisión
para explicar el historial de archivos, no como una instrucción de duplicar reviews nuevas.
