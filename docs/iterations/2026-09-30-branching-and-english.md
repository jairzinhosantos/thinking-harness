# Branching and English migration

## Accepted direction
The approved workflow uses main for formal baselines, develop for integration, task branches,
English-only project content, sober prose, and Mermaid with Draw.io where appropriate.
[Decision](../decisions/dec-0002-branching-and-english-standard.md).

## Migration scope
Translate active documentation, templates, metadata, diagram labels, and GitHub planning
content. Preserve document IDs, research states, source titles, and historical records.
Rewrite the root README as a project entry point. Add branch and diagram validation guidance.

## Review boundary
The task PR targets develop. It does not promote a formal baseline into main.
The progress-measurement choice and agent runtime design remain pending.
